# FilmReview aplikacija
FilmReview aplikacija napravljena u laravelu gdje korisnici mogu traziti filmove, dodavati ocjene i komentarisati.
Korisnici sa permisijama (admini) mogu dodavati nove filmove, editovati vec postojece te ih brisati. 
Svi imaju pristup stranici sa listom filmova, te svakom filmu, ali samo prijavljeni korisnici mogu dodavati ocjene i komentare.

# 
PHP verzija 8.2.12
XAMPP 8.2.12 - Apache , te MySQL baza
Node.js za frontend 

# 
Za kreiranje login forme, autentifikacije i autorizacije koristen je paket laravel breeze.
Kako bi se sve potpuno ucitalo, potrebna je instalacija paketa sa : npm install te pokretanje sa npm run dev.
